# {{name}}

An HMI app for the Mazda CMU, built with `revised-sdk`.

- `mod.yaml` describes the package (name, version, the Apps/Entertainment row).
- `ui/` is the app. `ui/main.js` registers it with `RevisedHMI`. It must be ES5.
- `ui/hmi.json` is generated by `revised-sdk build`; do not write it by hand.

```
revised-sdk build      # writes dist/{{name}}-<version>.rvp
```
